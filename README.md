# Bookstore Intelligence Mission

## Project Overview
This project uses web scraping to collect book information from Books to Scrape, a practice website for web scraping.

## Tools Used
- Python
- Requests
- BeautifulSoup
- Pandas
- Matplotlib

## Project Tasks
- Extract book information from the website.
- Clean and organize the scraped data.
- Analyze the collected book data.
- Generate a CSV file.
- Create visualizations and business recommendations.

## How to Run
1. Open the Jupyter Notebook file in Google Colab.
2. Install the required libraries.
3. Run the notebook cells in order.
4. Check the generated CSV file and analysis results.
